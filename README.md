# 💱 NekoCurrencies

Telegram-бот для автоматического распознавания валютных сумм в тексте и конвертации через актуальные курсы.

## Возможности

- **Распознавание валют** в тексте: `100 долларов`, `50€`, `1000 рублей`, `0.5 биткоин`
- **Математические выражения**: `(20 + 5) * 4 доллара` → `$100`
- **126 фиатных валют**, 27 криптовалют
- **3 режима обработки**: упрощённый, стандартный, расширенный (W2N/M2N)
- **Настраиваемые целевые валюты** — выберите во что конвертировать
- **Инлайн-режим** — используйте в любом чате через @username
- **Два языка**: русский и английский

## Быстрый старт

```bash
# 1. Клонировать
git clone https://github.com/aneek0/NekoCurrencies.git
cd NekoCurrencies

# 2. Настроить окружение
cp .env.example .env
# Заполнить .env: BOT_TOKEN, API-ключи

# 3. Установить зависимости
uv sync

# 4. Запустить
uv run python bot.py
```

## Переменные окружения

| Переменная | Обязательная | Описание |
|---|---|---|
| `BOT_TOKEN` | ✅ | Токен Telegram-бота (@BotFather) |
| `CURRENCY_FREAKS_API_KEY` | ❌ | API-ключ CurrencyFreaks (фоллбек для крипты) |
| `EXCHANGE_RATE_API_KEY` | ❌ | API-ключ ExchangeRate-API (резерв) |
| `ADMIN_IDS` | ❌ | ID администраторов через запятую |
| `RATE_LIMIT_PERIOD` | ❌ | Минимальный интервал запросов, сек (по умолчанию 1.0) |
| `CACHE_LIFETIME` | ❌ | Время жизни кэша курсов, сек (по умолчанию 600) |
| `LOG_LEVEL`, `LOG_FILE` | ❌ | Уровень и файл логов (по умолчанию INFO, `logs/bot.log`) |
| `DATABASE_FILE` | ❌ | Путь к SQLite (по умолчанию `data/users.db`) |

## Источники курсов

Приоритет (при `api_source=auto`):

1. **Frankfurter** — основной источник фиата (84 центральных банка, без ключа)
2. **НБРБ** — официальные курсы BYN (без ключа)
3. **CurrencyFreaks** — фиат и крипта (требует API-ключ)
4. **ExchangeRate-API** — резервный фиатный источник (требует API-ключ)
5. **CoinGecko** — крипта к USD (без ключа, используется автоматически)

Провайдер выбирается под запрошенные валюты: фиатный источник не мешает
получить крипту. Пользователь может выбрать конкретный источник в `/settings`
(1–4); выбранный идёт первым, остальные остаются фоллбеком.

## Команды

- `/start` (`/старт`) — главное меню
- `/help` (`/помощь`) — справка
- `/settings` (`/настройки`) — настройки (режим, валюты, API, язык, внешний вид)
- `/version` (`/версия`) — версия

## Структура проекта

```
bot.py          — Telegram: хендлеры, middleware, запуск
query.py        — разбор сообщения в Query(сумма, валюта) и режимы обработки
conversion.py   — политика конвертации и отрисовка ответа
rates.py        — источники курсов, порядок опроса, кэш, кулдаун
catalog.py      — каталог валют: коды, категории, подписи, алиасы, символы
settings.py     — реестр настроек: режимы, источники API, оформление, языки
math_parser.py  — вычисление арифметических выражений
database.py     — SQLite-хранилище настроек (Preferences)
keyboards.py    — inline-клавиатуры (строятся из settings/catalog)
localization.py — тексты (ru/en)
config.py       — переменные окружения и URL провайдеров
tests/          — тесты (pytest)
```
